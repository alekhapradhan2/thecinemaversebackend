# Goal Description

The goal is to update the Sacnilk Box Office scraper to scrape "Total Gross", "India Net", and "Overseas" collections. We will modify the database schema to store "Overseas Collection", update the calculation logic to compute daily India Net, Overseas, and Gross collections (where Gross is `(India Net × 1.18) + Overseas`), and update the HTML generation for blogs and the Box Office Panel to display the new columns and summaries.

## Proposed Changes

### Database Schema Updates
- **File:** `server.js`
- Modify `MovieSchema.boxOfficeDays` to add an `overseas` string field.
- Modify `MovieSchema.boxOffice` to add `grossCollection` and `overseasCollection` string fields.

### Scraper Logic Updates
- **File:** `server.js` (`scrapeSacnilkForMovie` function)
- Update the HTML parsing to extract `Total Gross`, `India Net`, and `Overseas` from the Sacnilk page.
- Calculate `dailyNetNum = Math.max(0, scrapedIndiaNetNum - previousIndiaNetNum)` (Handle edge cases so negative values don't happen).
- Calculate `dailyOverseasNum = Math.max(0, scrapedOverseasNum - previousOverseasNum)`.
- Calculate `dailyGrossNum = Math.round(dailyNetNum * 1.18) + dailyOverseasNum`.
- Update `movie.boxOfficeDays` array to store `overseas`, `net`, and `gross` values.
- Store cumulative totals: `movie.boxOffice.total = formatINR(scrapedIndiaNetNum)`, `movie.boxOffice.grossCollection = formatINR(scrapedTotalGrossNum)`, and `movie.boxOffice.overseasCollection = formatINR(scrapedOverseasNum)`.

### Blog & HTML View Updates
- **File:** `server.js` (`scrapeSacnilkForMovie` function)
- Update the **AI Prompt** to include the new metrics: "Today's India Net", "Today's Gross", "Today's Overseas", "Total India Net", "Total Gross", "Total Overseas".
- Update the **Box Office Summary** (stat-chips and info-table) in the HTML template to display "Total Gross", "India Net", and "Overseas".
- Update the **Box Office Table** (data-table) in the HTML template to rename the columns to "Day", "Date", "India Net", "Gross", "Overseas", etc., and inject the `overseas` values into the table rows.

## Verification Plan
1. Test the regular expression logic on a sample Sacnilk page to ensure `Total Gross`, `India Net`, and `Overseas` are extracted correctly.
2. Ensure mathematical calculations match exactly `Today's Gross = (Today's India Net × 1.18) + Today's Overseas`.
3. Check the HTML output generated by `scrapeSacnilkForMovie` to ensure the summary and table updates don't break responsive styles and look exactly as requested.
